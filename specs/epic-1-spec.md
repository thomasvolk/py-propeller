# 1 · Note Primitives DSL — Technical Specification

## Overview

Epic 1 implements the core DSL atoms — note constants, a rest value, and their modifier
operators — inside `propeller/notes.py`. Two immutable value types (`Note` and `Rest`) are
defined, all named constants are generated programmatically and exported cleanly for star-import,
and a shared `propeller/errors.py` is introduced to host the `PropellerError` hierarchy.

**Confidence Level:** 95% — All decisions resolved. Architecture, data model, and task table are
fully concrete. Residual 5%: `Z(120)` callable behaviour and `note * 0` validation are
implementation-time edge cases deferred to Epic 6 and do not block this specification.

## Architecture Overview

The module boundary is `propeller/notes.py`. It has no external dependencies and no observable
side effects on import (NF-2, NF-3).

**Components introduced in this epic:**

- `propeller/__init__.py` — empty package marker; does not re-export `notes` content.
- `propeller/errors.py` — defines `PropellerError` (base) and `PropellerValidationError`
  (subclass). Created here because Epic 1 is the first epic to raise `PropellerValidationError`.
  Epic 6 adds `PropellerConnectionError` to the same file without modifying existing classes.
- `propeller/notes.py` — defines `Note`, `Rest`, generates all named constants, defines `Z`/`z`,
  and exposes a complete `__all__`.

**Control flow for a DSL expression:**

```
from propeller.notes import *   # all constants injected into caller namespace

C4                              # Note(pitch=60, duration=1.0, velocity=100)
C4(120)                         # Note.__call__(120) → Note(pitch=60, duration=1.0, velocity=120)
C4 * 2                          # Note.__mul__(2)   → Note(pitch=60, duration=2.0, velocity=100)
C4(120) * 2                     # chain:            → Note(pitch=60, duration=2.0, velocity=120)
Z * 2                           # Rest.__mul__(2)   → Rest(duration=2.0)
```

`Note` and `Rest` are implemented as `@dataclass(frozen=True)`. This gives free `__eq__`,
`__hash__`, and `__repr__`, and allows `dataclasses.replace()` as the copy-with-override
mechanism inside `__call__` and `__mul__`. Both operators return new instances; originals
are never mutated (NF-1). `Note.__call__` validates the velocity argument against [0, 127]
and raises `PropellerValidationError` immediately on failure (F-13).

All note constants are generated by a module-level `for` loop that iterates over a pitch-name
table and calls `globals()[name] = Note(pitch)`. A parallel `__all__` list is built in the same
loop, then `Z` and `z` are appended to it. No metaprogramming or lazy generation is used.

**MIDI pitch formula:**

```
MIDI(name, octave) = (octave + 1) × 12 + semitone_offset
```

Semitone offsets: C=0, Cs/Df=1, D=2, Ds/Ef=3, E=4, F=5, Fs/Gf=6, G=7, Gs/Af=8, A=9,
As/Bf=10, B=11. This gives C0=12, C4=60, C8=108 (matching AC-16, AC-1, AC-17).

## Components

### `propeller/errors.py`

Defines `PropellerError(Exception)` and `PropellerValidationError(PropellerError)`.
Both are importable from `propeller.errors`. Epic 6 extends this file with
`PropellerConnectionError`.

### `propeller/notes.py`

Defines `Note` and `Rest`, generates all note constants for octaves 0–8 (including both
enharmonic spellings for every accidental), defines `Z = Rest()` and `z = Rest()`, and
populates `__all__` so that star-import exposes exactly the named constants plus `Z`/`z`
with no module-level noise.

### `Note`

`@dataclass(frozen=True)` with fields `pitch: int`, `duration: float = 1.0`,
`velocity: int = 100`. `__mul__` returns `dataclasses.replace(self, duration=beats)`;
`__call__` validates velocity in [0, 127], then returns `dataclasses.replace(self, velocity=velocity)`.
Equality is value-based via the generated `__eq__`.

### `Rest`

`@dataclass(frozen=True)` with field `duration: float = 1.0`. `__mul__` returns
`dataclasses.replace(self, duration=beats)`. `Rest` is not callable.

## Data Model

| Type | Fields | Notes |
|------|--------|-------|
| `Note` | `pitch: int`, `duration: float = 1.0`, `velocity: int = 100` | `@dataclass(frozen=True)`. `velocity` validated in [0, 127] at `__call__` time. |
| `Rest` | `duration: float = 1.0` | `@dataclass(frozen=True)`. No pitch, no velocity. |
| `PropellerError` | — | Subclass of `Exception`. Base for all library exceptions. |
| `PropellerValidationError` | — | Subclass of `PropellerError`. Raised for DSL/structural validation failures. |
