# 1 · General MIDI Drum Note Constants — PRD

## Overview

Deliver the `propeller.notes.drums` module so that a user composing a drum
part can reference each General MIDI Level 1 drum sound by a descriptive,
readable name instead of memorizing its numeric MIDI note value. Names are
derived directly from the standard General MIDI drum sound name, and drum
sounds that were only added in General MIDI Level 2 are excluded.

**Confidence Level:** 92% — naming, representation, and discoverability are
now fully specified and testable; only very minor implementation-level
details (e.g. exact `__all__` ordering) remain unresolved, and none of
those affect user-observable behaviour.

---

## User Journeys

### UJ-1 · Composing a drum part with named constants

A user writing a drum track imports `propeller.notes.drums` and references
percussion sounds by name (e.g. `SnareDrum1`, `ClosedHihat`) instead of raw
MIDI note numbers when building note events for the track. Because each
constant is a note-like value of the same kind as the existing pitch
constants, it can be placed directly into a `Track` alongside them.

### UJ-2 · Discovering available drum names

A user who doesn't remember the exact constant name for a percussion sound
browses the module's public interface to find it, without needing to open
the external General MIDI drum note reference table.

---

## Functional Requirements

| ID  | Requirement |
|-----|-------------|
| F-1 | The module provides a distinct, importable, named constant for each of the 47 General MIDI Level 1 percussion sounds mapped to MIDI note numbers 35 through 81. |
| F-2 | Each constant's name is derived from its General MIDI Level 1 drum sound name with spaces removed (e.g. "Bass Drum 2" becomes `BassDrum2`). |
| F-3 | Each constant resolves to the correct MIDI note number for its drum sound, per the mapping in `specs/briefing.md`. |
| F-4 | The 14 drum sounds tagged as General MIDI Level 2 additions (MIDI note numbers 27–34 and 82–87) are excluded from the module's public constants. |
| F-5 | Where a source drum sound name also contains a hyphen, the hyphen is removed in addition to spaces when deriving the constant name (e.g. "Closed Hi-hat" becomes `ClosedHihat`). |
| F-6 | Each drum constant is a note-like value of the same kind as the existing `propeller.notes` pitch constants, so it can be used directly wherever a pitch constant is accepted (e.g. placed directly into a `Track`). |

---

## Non-Functional Requirements

| ID   | Requirement |
|------|-------------|
| NF-1 | The module defines a public `__all__` list enumerating every drum constant name, consistent with the existing `propeller.notes` module's export pattern. |

## Acceptance Criteria

| ID   | Given | When | Then |
|------|-------|------|------|
| AC-1 | the `propeller.notes.drums` module | a user imports it | a named constant exists for every General MIDI Level 1 drum sound with MIDI note numbers 35 through 81 |
| AC-2 | a drum sound name such as "Bass Drum 2" | the corresponding constant name is derived | it matches the source name with spaces removed (`BassDrum2`) |
| AC-3 | any drum constant | its value is inspected | it resolves to the correct MIDI note number listed for that drum sound |
| AC-4 | the General MIDI Level 2 tagged drum sounds (note numbers 27–34, 82–87) | the module's public constants are listed | none of the Level 2 sounds appear among them |
| AC-5 | the `propeller.notes.drums` module | a user wants to see all available drum names | they can do so without consulting external documentation |
| AC-6 | a drum sound name containing a hyphen, such as "Closed Hi-hat" ("Pedal Hi-hat", "Open Hi-hat") | the corresponding constant name is derived | it matches the source name with both spaces and hyphens removed (`ClosedHihat`) |
| AC-7 | a drum constant such as `SnareDrum1` | it is placed into a `Track` alongside pitch constants | it behaves as a valid note event exactly as a pitch constant would |
| AC-8 | the `propeller.notes.drums` module | its `__all__` attribute is inspected | it contains the name of every public drum constant defined by the module |
