# CLAUDE.md

## User expertise

The user is an experienced Python developer with deep expertise in:

- Python language features: idiomatic Python, metaclasses, decorators, descriptors, generators, type system, dataclasses, protocols
- DSL design and implementation: building internal and external DSLs in Python, parser combinators, AST manipulation, domain-specific abstractions
- Algowave: algorithmic/generative music composition concepts and tooling
- MIDI: MIDI protocol, message types (note on/off, CC, SysEx, clock, etc.), sequencing, timing, real-time MIDI I/O, and MIDI file format

When discussing design, suggest Pythonic and DSL-oriented approaches. When discussing music features, use accurate MIDI and algowave terminology. Assume the user shares this expertise — no need to over-explain basics in these domains.
